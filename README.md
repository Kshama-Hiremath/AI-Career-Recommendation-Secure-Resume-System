# 🚀 AI Career Recommendation Platform with Secure Resume Processing

An AI-powered web application that analyzes resumes, provides personalized career recommendations, offers an intelligent AI career advisor, and securely processes user data.

---

## ✨ Features

- 📄 AI Resume Analysis
- 🤖 AI Career Advisor
- 💼 Personalized Career Recommendations
- 🔍 Skill Gap Analysis
- 📊 Resume Insights Dashboard
- 🔐 Secure Resume Processing
- 🌙 Modern Responsive UI
- ☁️ Supabase Integration
- ⚡ Fast Vite + React Application

## 🚀 Installation

```bash
git clone https://github.com/Kshama-Hiremath/AI-Career-Recommendation-Secure-Resume-System.git

cd AI-Career-Recommendation-Secure-Resume-System

npm install

npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file and configure:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

Configure your own Gemini API Key from the application settings before using AI features.
